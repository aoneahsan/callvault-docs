# What a white-label CallVault includes

CallVault's platform group is the mobile app. A licence for it covers these parts, all built from the same code as CallVault.

## The Android app

- A signed APK with your app name, icon, colours and package name.
- English and Urdu, as CallVault ships them. Another language is [custom work](https://callvault.aoneahsan.com/white-label/custom-work).
- Recording, import, playback, search, notes and export, working without a connection, the same as [in CallVault](../user-guide/recording.md).

## Download and updates

- A download page on your domain with the APK and its `SHA256SUMS` file.
- The self-update: after the first install the app downloads each new APK, checks its size, SHA-256, package name and signing certificate, then opens the Android installer. The [install guide](../getting-started/install.md) shows what your users see.
- The release notices you publish from the admin dashboard, including a required update when one is needed.

## Accounts, backup and administration

- Google sign-in and private cloud backup, off until each user turns it on.
- The signed-in web library your users open from your domain.
- The admin dashboard where you set plan limits, confirm plan requests and publish update notices ([admin guide](../admin-guide/dashboard.md)).

## Not included

- An iPhone app. iPhone doesn't let an ordinary app record calls, so there is no iPhone build. Anything for iPhone users is agreed as custom work.
- A Google Play listing. The app ships as your own signed APK from your site. If you choose to publish under your own store account, that account and its review are yours.
- The source code, which changes hands only with a [buyout](https://callvault.aoneahsan.com/white-label/buyout).
