# Changelog

Release notes for CallVault, newest first. For an RSS/Atom feed of the same notes, see the
[Updates feed](/updates).

## v1.3.0 — 2026-09-17 (prerelease)

Recordings back up as private files, replacing public file links. Each track plays and exports on its own, or as a combined recording. Capture setup shows whether capture is ready. Guests keep 100 recordings, and nothing is deleted at the limit. Free, Pro and Family plans set backup limits; everything else stays free. Updates are verified against the release policy and the installed signature. Every new screen ships in English and Urdu. This build is a prerelease for device testing; the download button appears once a release is stable.

## v1.2.0 — 2026-07-22

Package and platform refresh (Riverpod, routing, charts and more brought current), web
dashboard polish (accessibility, localization, URL state), SEO and discoverability
improvements, and this documentation site. Under-the-hood reliability improvements to the
recording and sync pipeline.

## v1.1.0 — first public release

Record your own calls, play them back with speed controls, search your history, and
optionally back recordings up to storage you control.
