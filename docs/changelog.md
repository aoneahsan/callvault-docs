# Changelog

Release notes for CallVault, newest first. For an RSS/Atom feed of the same notes, see the
[Updates feed](/updates).

## v1.2.0 — 2026-07-22

Package and platform refresh (Riverpod, routing, charts and more brought current), web
dashboard polish (accessibility, localization, URL state), SEO and discoverability
improvements, and this documentation site. Under-the-hood reliability improvements to the
recording and sync pipeline.

## v1.1.0 — first public release

Record your own calls, play them back with speed controls, search your history, and
optionally back recordings up to storage you control.
