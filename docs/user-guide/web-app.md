# The web app

CallVault has a web dashboard built from the same codebase as the phone app, hosted at
[callvault.aoneahsan.com](https://callvault.aoneahsan.com). Sign in with the same account
and you can browse and manage your recordings from any browser.

## What you can do on the web

- **Browse** your recordings, grouped by day, with direction, number or contact, and
  duration.
- **Play** a recording — the web player streams the backed-up audio from its URL.
- **Search and filter** by number, contact, or note; the active tab, filter, and search
  term live in the URL (`?tab=`, `?filter=`, `?q=`) so a refresh or a shared link restores
  your place.
- **Favorite and add notes** — changes sync back to the phone.
- **Manage your** [profile and preferences](/user-guide/profile), and
  [delete your account](/user-guide/account-deletion) if you choose.

## The one thing to know

The web app shows only your **backed-up** recordings. By design it has no local database
of its own, so anything that only ever lived on the phone (never backed up, or kept on
device because it was over the [100 MB cap](/user-guide/sync-backup#the-100-mb-per-file-cap))
won't appear on the web. It's a window into your cloud copy, not a second recorder.

## Accounts

If your account has been disabled by an administrator, the web app routes you to a clear
"account disabled" screen rather than showing an empty app. Admins have an extra dashboard —
see the [Admin guide](/admin-guide/dashboard).
