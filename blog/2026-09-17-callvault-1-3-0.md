Three things stand out in 1.3.0, a prerelease for device testing. A cloud copy is now a private file, a call opens as the separate tracks CallVault found, and one screen tells you whether capture is ready before the call that matters.

<!-- truncate -->

## Where 1.2.0 left you

Playback, search, notes and export all worked. A backed-up recording, though, was one file behind a public link, and no single track was reachable on its own. Nothing told you, before a call, whether capture was ready.

## What 1.3.0 changes

A cloud copy is a private file now. You can open it in the app and the web library, and so can a CallVault administrator. No recording has a public link, and private cloud backup is still off until you turn it on. Backups from 1.2.0 were moved already; you do nothing.

A call now opens as the tracks CallVault found, each labeled with its real source. Play one. Export one, or ask for a combined recording mixed from what is there.

Capture setup lists the microphone, phone state and notifications as Allowed or Needs action, with the battery exemption and the optional accessibility assist below them. It tells you whether capture is ready.

Without an account, you keep 100 recordings on the phone. At the limit, new recording pauses. Nothing is deleted, and playback, search and export keep working; signing in with Google removes the count limit.

Free, Pro and Family plans set private cloud backup limits and nothing else. Recording, import, playback, search, notes and export are free on every plan.

Updates come from the website release. The app checks the download's size, SHA-256 and version code against the release policy, and the package name and signing certificate against the installed app, then opens the Android installer.

Every new screen ships in English and Urdu, on a refreshed brand color.

## What to do with this build

This build is a prerelease for device testing. It sits on the public releases page with its APK and a `SHA256SUMS` file; the download button appears once a release is stable. 

Check the APK against SHA256SUMS, install it, then open Capture setup until it reads Capture is ready. Make one test call after that. Your phone decides which audio sources a normal app can hear, and on many phones the other person is clear only on speaker. Listen before you rely on this build for a call that matters.

Recording laws vary; you are responsible for getting any consent required where you are. This is general information, not legal advice.
