CallVault 1.2.0 brings the app's dependencies and platform up to date, polishes the web
dashboard, and adds this documentation site.

<!-- truncate -->

## What's new

- **Platform refresh** — Riverpod, routing, charts, and other packages brought current.
- **Web dashboard polish** — accessibility fixes, localization, and URL state so tabs,
  filters, and search survive a refresh or a shared link.
- **SEO and discoverability** improvements across the web surfaces.
- **This documentation site.**
- **Reliability** — under-the-hood improvements to the recording and sync pipeline.
